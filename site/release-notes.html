v2.10 업데이트 안내

고객 접수가 태스크 목록처럼 편해지고, 주간업무에 회의용 화면이 생겼습니다.

신규건 개선건 변경건 수정건

고객 접수

신규

연결한 태스크 변경/제거

접수에 연결한 태스크를 나중에 다른 태스크로 바꾸거나 연결을 해제할 수 있습니다. 태스크를 연결할 때 새로 만들 수도 있고, 이미 있는 태스크를 골라 연결할 수도 있습니다.

  • 실행 전 확인 창에서 기존 태스크의 이력(변경 이력, 댓글, 하위 태스크, 첨부)을 미리 볼 수 있습니다.
  • 이 접수에서 새로 만든 태스크 중 이력이 없는 태스크는 휴지통으로 이동합니다. 이력이 있거나, 이미 있던 태스크를 골라 연결한 경우에는 연결만 끊습니다. 휴지통으로 간 태스크는 복구할 수 있습니다.
  • 연결 변경 내역은 접수 변경 이력에 남습니다.
신규

고객 접수 설정 탭 추가

고객 관리 화면에 '설정' 탭이 생겨 유형, 상태, 우선순위 값을 직접 편집할 수 있습니다. 설정 하나가 모든 고객에 공통으로 적용됩니다.

  • 기본으로 워크스페이스 소유자·관리자만 편집할 수 있고, 권한 설정의 '고객 목록 · 설정' 항목에서 바꿀 수 있습니다.
개선

목록 컬럼 추가

고객 접수 목록과 고객별 접수 탭에 다음 컬럼이 추가되었습니다.

  • 연결한 프로젝트
  • 최종 수정일 (댓글을 달아도 갱신)
  • 작성자, 진행률, 예상/실제 시작일, 예상/실제 종료일
개선

태스크 목록처럼 편해진 목록

컬럼 순서를 드래그로 바꾸고, 제목 열 폭을 조절하고, 컬럼 머리글에서 정렬하거나 필터링할 수 있습니다. 작성자 필터도 새로 생겼습니다.

  • 유형, 상태, 우선순위는 설정에서 정한 순서대로 정렬됩니다.
  • 담당자, 작성자, 고객사는 이름순으로 정렬됩니다. 담당자가 없는 접수는 항상 맨 뒤에 나옵니다.
신규

바로 수정

유형, 상태, 우선순위, 담당자, 진행률, 날짜를 목록 칸이나 상세 패널에서 바로 고칠 수 있습니다.

  • 상태를 '완료'로 바꾸면 진행률이 100%가 되고, 완료에서 되돌리면 0%가 됩니다.
  • 처음 '진행'이나 '완료'로 바꿀 때 실제 시작일이 비어 있으면 오늘 날짜가 들어갑니다.
신규

고객사 변경

접수를 같은 워크스페이스의 다른 고객사로 옮길 수 있습니다. 옮기면 그 고객사의 새 접수 번호가 붙습니다.

신규

전체 화면으로 작성

새 접수를 넓은 화면에서 쓸 수 있습니다. 팝업에서 쓰던 내용과 이미지가 그대로 넘어갑니다.

개선

용어 통일

화면마다 달랐던 용어를 하나로 맞췄습니다. 예: '연결한 태스크', '작성일', '새 접수'.

건의함

신규

'태스크로 등록' 버튼

관리자는 건의 상세에서 '태스크로 등록' 버튼으로 건의를 바로 태스크로 만들 수 있습니다.

  • 건의 본문과 이미지는 그대로 복사되므로 더 이상 붙여넣지 않아도 됩니다.
  • 등록한 태스크의 번호, 제목, 상태는 건의 상세에 표시됩니다.

태스크 / 주간업무

신규

'회의 모드' 추가

주간업무의 '회의 모드' 버튼을 누르면 화면 전체에 보고용 태스크만 프로젝트별로 보여 줍니다. 개인 필터 없이 누가 열어도 같은 화면이라 회의 때 함께 보기 좋습니다.

  • 프로젝트 이름 옆에 고객사와 담당자(프로젝트에서 'PM(관리자)' 역할인 멤버)가 표시됩니다.
  • 워크스페이스 관리자는 설정에서 프로젝트 순서를 정할 수 있습니다. 이 순서는 주간업무 프로젝트 칩에도 적용됩니다.
  • 보고 있는 주차의 내용을 문서(.docx)로 내려받을 수 있습니다.
변경

주간업무 화면 정리

  • '담당자별' 탭을 없애고 프로젝트별 화면만 남겼습니다.
  • 열이 '지난주 · 이번주'로 바뀌었습니다. 지난주에는 진행·완료 태스크만 보이고, 아직 끝나지 않은 진행 태스크는 이번주에 나옵니다.
  • 사이드바에서 숨긴 프로젝트도 주간업무에는 나옵니다.
  • 주차는 목요일 기준으로 셉니다. 예: 10/26~11/1은 10월 5주차입니다.
신규

이슈관리 프로젝트에도 역할 추가

WBS처럼 멤버별로 역할을 지정할 수 있습니다. 'PM(관리자)' 역할은 회의 모드 담당자 표시에 쓰이므로 이름을 바꾸거나 삭제할 수 없습니다.

개선

전체 태스크 탭에 프로젝트명 컬럼 추가

권한 / 관리

개선

프로젝트 관리자도 GitHub 연동 설정

레포 조회, 매핑, 연결을 할 수 있지만 GitHub 앱 설치는 워크스페이스 관리자만 할 수 있습니다.

개선

그룹/권한 멤버 관리 개선

현재 멤버만 인원 수와 함께 목록으로 보입니다. 사람을 검색해 여러 명을 한 번에 추가하고, 줄마다 있는 버튼으로 바로 제외할 수 있습니다. 전역 권한 창에 멤버가 20명까지만 보이던 문제도 고쳤습니다.

버그 수정

수정

주간업무 '보고용 기준' 보기에서 날짜가 있는 태스크가 '날짜 미정' 칸에 나오던 문제를 고쳤습니다.

수정

주간업무에서 일정이 다다음 주 이후이거나 시작일만 지난 날짜로 있는 태스크가 '날짜 미정' 칸에 나오던 문제를 고쳤습니다. 이제 '날짜 미정'에는 날짜가 하나도 없는 태스크만 나옵니다.

수정

전용 프로젝트만 있는 사용자가 로그인하면 대시보드가 계속 로딩되던 문제를 고쳤습니다. 이제 로그인 후 바로 전용 프로젝트 화면으로 이동합니다.
