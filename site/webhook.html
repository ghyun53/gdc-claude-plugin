GDC 웹훅

웹훅 연동 안내서

Mattermost에 GDC 알림 전용 채널을 만들고 Incoming Webhook으로 연결한 뒤, 그 주소를 GDC 알림 설정에 등록합니다. 채널 생성 → 웹훅 연동 → 알림 등록 순서로 진행합니다.

GDC 화면은 한국어와 영어를 모두 지원합니다. 3단계의 화면은 선택한 언어를 따라갑니다.

01

채널 생성

GDC 알림만 모아서 받을 전용 채널을 Mattermost에 새로 만듭니다.

1 채널 생성 · 1-1 새 채널 생성 시작

새 채널 생성 시작

Mattermost 사이드바에서 채널 추가 메뉴를 엽니다.

  1. 1

    왼쪽 사이드바 「채널」 옆 채널 추가(+) 아이콘을 클릭합니다.

  2. 2

    새로운 채널 생성을 선택합니다.

실제 화면
1 채널 생성 · 1-2 채널 정보 입력

채널 정보 입력

채널 이름과 목적을 입력하고 공개 범위를 정합니다.

  1. 1

    채널 이름을 입력합니다. (예: GDC-테스트)

  2. 2

    공개 채널 또는 비공개 채널을 선택합니다. 알림 수신용이라면 비공개 채널을 권장합니다.

  3. 3

    채널 목적에 용도를 적어 둡니다. (예: GDC 알림 수신용)

  4. 4

    채널 만들기를 클릭합니다.

이 채널 이름은 잠시 후 Incoming Webhook을 만들 때 다시 선택합니다.

실제 화면
02

웹훅 연동

Mattermost 관리자 화면에서 Incoming Webhook을 만들고, 1단계에서 만든 채널과 연결합니다.

2 웹훅 연동 · 2-1 통합 메뉴 열기

통합 메뉴 열기

제품 메뉴에서 통합 관리 화면으로 이동합니다.

  1. 1

    왼쪽 위 Mattermost 메뉴를 클릭합니다.

  2. 2

    통합을 선택합니다.

실제 화면
2 웹훅 연동 · 2-2 Incoming Webhook 선택

Incoming Webhook 선택

통합 목록에서 Incoming Webhook 카드를 클릭합니다.

  1. 1

    전체 Incoming Webhook 카드를 클릭합니다. 외부 시스템에서 메시지를 받는 기능입니다.

실제 화면
2 웹훅 연동 · 2-3 Webhook 추가 시작

Webhook 추가 시작

새 Incoming Webhook 추가 화면으로 이동합니다.

  1. 1

    오른쪽 위 Incoming Webhook 추가하기를 클릭합니다.

실제 화면
2 웹훅 연동 · 2-4 채널 지정 후 저장

채널 지정 후 저장

웹훅이 메시지를 보낼 채널을 1단계에서 만든 채널로 지정합니다.

  1. 1

    채널 드롭다운에서 1단계에서 만든 채널을 선택합니다. (예: GDC-테스트)

  2. 2

    제목·설명·사용자 이름·프로필 사진은 필요할 때만 채웁니다. 비워 두면 기본값이 사용됩니다.

  3. 3

    하단 저장을 클릭합니다.

실제 화면
2 웹훅 연동 · 2-5 Webhook URL 복사

Webhook URL 복사

생성된 Webhook의 URL을 복사해 둡니다. 3단계에서 그대로 사용합니다.

  1. 1

    전체 Incoming Webhook 목록에서 방금 만든 항목을 찾습니다.

  2. 2

    URL 옆 복사 아이콘을 클릭합니다.

이 URL은 채널 하나에 고정됩니다. 채널을 바꾸려면 Webhook을 다시 만들어야 합니다.

03

GDC에 알림 연결

복사한 Webhook URL을 GDC 알림 설정에 등록하면 연동이 끝납니다.

3 GDC에 알림 연결 · 3-1 알림 설정에 URL 등록

알림 설정에 URL 등록

GDC 설정의 알림 탭에서 웹훅 유형과 URL을 지정합니다.

  1. 1

    오른쪽 위 프로필 아이콘 → 설정을 클릭합니다.

  2. 2

    알림 탭으로 이동합니다.

  3. 3

    외부 웹훅이 켜져 있는지 확인하고, 웹훅 유형에서 Mattermost를 선택합니다.

  4. 4

    웹훅 URL에 2단계에서 복사한 주소를 붙여넣습니다.

  5. 5

    테스트 전송으로 채널에 메시지가 오는지 확인합니다.

아래 이벤트 카테고리 표에서 초대·댓글·멘션(@)·담당자 지정 등 알림을 받을 이벤트를 항목별로 켜고 끌 수 있습니다.

더 알아보기

GDC의 다른 안내서로 이어집니다.

GDC 사용 매뉴얼 GDC의 구성 단위와 사이드바 각 탭의 역할·권한을 화면과 함께 안내합니다. GDC MCP 플러그인 사용 안내서 Claude Code·Claude 데스크탑 앱의 대화창에서 GDC 태스크를 조회·생성하고, 작업 요청 문서와 태스크를 연결하는 방법을 안내합니다. GDC GitHub 연동 안내서 워크스페이스에 GitHub을 연결하고 프로젝트에 레포를 붙여, 이슈·PR을 태스크와 함께 쓰는 방법을 안내합니다.
