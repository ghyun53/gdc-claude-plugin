## 요청 내용

GDC 태스크 #771 「GDC 업데이트 내역 공지사항 업로드」 본문의 v2.10 업데이트 내역 초안을, 공지사항에 화면 캡처로 올릴 수 있도록 소프트웨어 업데이트 노트 형태의 HTML 페이지로 만든다.

- 작업 위치: gdc-claude-plugin, `main` 기준 브랜치 `docs/release-notes-v2.10` (이 레포에 develop 없음 — 사용자 확인)
- 내용 범위: 태스크 본문 초안 그대로. 「배포 전에 확인할 것」(내부 메모)과 초안에 없는 하위 태스크 5건(#731·#730·#726·#722·#717)은 넣지 않음 (사용자 확인)

- 추가 요청: 실제 화면을 캡처해 바뀐 부분을 빨간 네모로 표시해 각 항목에 넣는다. 운영(`gdc.gemiso.com`) 테스트 워크스페이스 3에서 촬영(사용자 지시 — 운영에 v2.10이 이미 배포돼 있음을 화면으로 확인).

## 참고 사항

- 회의 모드 설정 창에 '구글 내보내기' 탭이 운영 화면에 보임 — 초안 메모는 '화면에서 꺼 두었으니 공지에 쓰면 안 됨'이라 불일치. 캡처에 탭이 찍혀 있으니 공지 전 확인 필요.
- 캡처 일관성을 위해 라이트 테마 고정(다크 모드 미지원). 요약 개수는 항목 태그에서 JS로 계산.
- 초안 문장은 그대로 옮기고 표기만 정리(따옴표 통일 등). 운영 배포 여부 확인은 공지 전 사용자 몫(태스크 본문 「배포 전에 확인할 것」 1번).
