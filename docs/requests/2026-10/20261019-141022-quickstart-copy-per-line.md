## 요청 내용

MCP 안내서(`site/index.html`) 첫 화면 「바로 시작하기」(Claude Code 쪽)에서

1. 설치 커맨드 3줄을 한 줄씩 따로 복사할 수 있게 한다.
2. 1번(uv 확인)과 2번(설치) 사이에 「클로드 CLI 접속」 단계(`/claude`)를 추가한다.

## 배경

설치 3줄이 `code.blk` 하나에 묶여 있어 클릭하면 세 줄이 한꺼번에 복사됐다. 세 커맨드는 Claude Code에 한 줄씩 차례로 붙여넣어야 하므로 복사 단위가 실제 사용 단위와 어긋났다.

## 작업 결과

- [x] 설치 단계의 3줄짜리 `code.blk` 1개 → 줄별 `code.blk` 3개로 분리(`.cmdlines` 래퍼, 간격 4px). 기존 클릭 복사 로직·호버 라벨·키보드 접근을 그대로 재사용해 JS 무변경
- [x] 1·2번 사이에 「클로드 CLI 접속」(`/claude`) 단계 추가, 이후 단계 번호 2~4 → 3~5로 재정렬
- [x] 리드 문구 "네 단계" → "다섯 단계" 및 `data-en`(Four → Five steps) 동기화
- [x] `.quick-list li` 라벨 칼럼 92px → 124px (「클로드 CLI 접속」 줄바꿈 방지)

## 참고 사항

- 변경 파일: `site/index.html` 1개. Claude Desktop 쪽 「바로 시작하기」는 무변경(라벨 칼럼 폭만 공유).
- MCP 도구·서버 동작과 무관한 문서 페이지 수정이라 로컬 사전 검증(WS3) 대상 아님. 플러그인 동작 변경이 없어 `plugin.json` 버전도 그대로 둔다.
- `/claude`는 사용자가 지정한 표기 그대로 넣었다. 터미널에서 Claude Code를 띄우는 실제 명령은 슬래시 없는 `claude`라, 표기를 바꿀지는 후속 확인 대상.
