## 요청 내용

GDC 사용 매뉴얼(`site/manual.html`, https://seonmikii.github.io/gdc-claude-plugin/manual.html) 왼쪽 목차에서 '워크스페이스 종속'에만 있던 탭별 하위 인덱스를 **'워크스페이스 전역'을 포함한 나머지 항목에도** 추가한다. 작업은 새 브랜치(`docs/manual-toc-all-sub`)에서 한다.

진행 중 추가 지시:
- '권한 설정에 관한 설명'에도 하위 인덱스를 추가한다.

## 배경

- 0edf10c에서 '워크스페이스 종속' 아래에만 탭 링크 8개를 넣었다. 나머지 그룹은 그룹 이름만 있어 공지사항·휴지통 같은 개별 탭 안내로 바로 갈 수 없다.
- 본문의 각 탭 블록에는 이미 `id`(`t-announcements` 등)가 있어 목차 링크만 추가하면 된다.

## 수행 계획

1. `03 탭별 안내` 목차의 각 그룹 아래에 본문 순서대로 탭 링크를 추가한다.

```
03 탭별 안내
 ├ 워크스페이스 전역
 │   ├ 공지사항            (+) #t-announcements
 │   ├ 건의함              (+) #t-suggestions
 │   └ 알림                (+) #t-notifications
 ├ 워크스페이스 종속
 │   └ 대시보드 … 프로젝트  (기존 8개, 변경 없음)
 ├ 별도의 접근 권한 필요
 │   ├ 휴지통              (+) #t-trash
 │   ├ 종료된 프로젝트      (+) #t-closed
 │   └ 워크스페이스 설정    (+) #t-ws-settings
 ├ 권한 설정에 관한 설명    (위치·단계 변경 없음)
 ├ 시스템 관리자용
 │   └ 시스템 관리          (+) #t-system
 └ 개인 설정
     └ 설정                (+) #t-settings
```

2. 3단계 들여쓰기 스타일(`.toc ol ol ol`)은 0edf10c에서 이미 추가돼 있어 CSS·스크립트는 고치지 않는다.
3. 검증: 목차의 모든 `href`가 본문 `id`와 1:1로 맞는지, 깨진 앵커가 없는지 확인한다.

4. (추가 지시) '권한 설정에 관한 설명' 아래에 소제목 4개(기본 권한과 추가 권한 · 필터 권한과 메뉴 권한 · 프로젝트별 권한 · 프로젝트가 보이지 않을 때)를 링크로 넣는다. 앞의 두 소제목에는 `id`가 없어 `perm-basic`·`perm-filter-menu`를 붙이고, 소제목으로 이동했을 때 화면 위에 바짝 붙지 않도록 `h4.sub-h`에 `scroll-margin-top`을 준다.

범위 밖: 본문 내용·캡처, `01`·`02` 장의 목차, 그 밖의 탭 안 소제목(h4) 단위 인덱스.
