## 요청 내용

GDC 사용 매뉴얼(`site/manual.html`, https://seonmikii.github.io/gdc-claude-plugin/manual.html)을 **현재 운영 배포 버전(https://gdc.gemiso.com)** 기준으로 갱신한다. 화면 캡처도 운영 배포 버전에서 다시 찍는다.

진행 중 추가 지시:
- 캡처는 **제머나이소프트(WS6) 워크스페이스 데이터**로 찍는다.
- 실명 등 개인 정보는 **마스킹**한다.
- **데이터가 없는 화면은 예전 사진을 그대로 쓴다** — 대시보드 내 업무, 리소스 예약 포함.
- 데이터를 임의로 만들지 않는다.

## 배경

- 매뉴얼은 #670(5ae9da1)에서 **localhost 개발 환경 기준**으로 작성됐다. 개발 브랜치(`feat/gdc-499-member-groups`, #500 권한 개편)에만 있는 기능(그룹·권한 탭, 기본/추가 권한, 필터·메뉴 권한)이 운영에는 없다.
- 운영은 gdc-service `origin/develop`(마지막 머지 #227, 2026-10-01)과 일치함을 화면·코드로 확인했다.

## 수행 계획

1. 운영 로그인 세션 확보 — 사용자가 보이는 창에서 직접 로그인(자격 증명 미취급).
2. 운영 화면과 `origin/develop` 코드로 매뉴얼 본문을 대조해 차이를 고친다.
3. 캡처를 운영 화면에서 다시 찍는다 — 기존 크기(1440×900 기준, 부분 크롭은 기존 크기)·WebP·빨간 네모/번호 라벨 유지, 실명·이메일·연락처·웹훅 주소·S3 설정값은 흐림 처리.
4. `site/manual.html` 이미지·본문·푸터를 교체한다.
5. 로컬에서 페이지를 열어 이미지 표시·목차 링크를 확인한다.
6. `docs/INDEX.md` 이력에 한 줄 추가한다.

## 참고 사항

### 본문 수정 (운영 = `origin/develop` 기준)
- **워크스페이스 설정**: 탭을 `일반·멤버·그룹·권한·리소스·기타` → `일반·멤버·리소스·기타`로 수정. 리소스·기타는 소유자·관리자만 보임(`WorkspaceSettingsPage.tsx:129`).
- **권한 설정에 관한 설명**: 운영에 없는 기본/추가 권한·그룹·필터 권한·메뉴 권한 설명을 걷어내고, 역할 4종 + 멤버별 `이슈 대시보드`(고객 접수 탭)·`고객 탭`(고객 관리 탭) 체크, 기타 탭의 멤버 관리/초대·프로젝트 생성 권한으로 교체. 메뉴별 권한은 '준비 중'으로 명시(`use-permission.ts:51-52`, `Sidebar.tsx:293-294`).
- **프로젝트가 보이지 않을 때**: 소유자·관리자는 전체, 멤버·뷰어는 공개+참여 프로젝트(`projects/views.py:340-350`). 필터 권한 조정 항목 삭제, 공개 전환 위치를 프로젝트 설정 탭으로 수정.
- **고객 접수**: 접근 조건을 '메뉴 권한' → '소유자 또는 이슈 대시보드 체크 멤버'로 수정.
- **고객 관리**: 카드형·활동 상태별 묶음(정상 진행/최근 활동 없음)·장기 미업데이트 기준, 상세 화면 구성(고객 정보·담당자·프로젝트 / 접수 내역·관련 태스크)으로 수정. 접근 조건 추가.
- **리소스 예약**: '메인 워크스페이스에만 ON' → '기능을 켠 워크스페이스에만 표시'. 운영 4개 워크스페이스 모두 기능 꺼짐을 확인.
- **종료된 프로젝트**: 종료 권한을 '메뉴 권한' → '워크스페이스 소유자·관리자 또는 프로젝트 관리자'(`projects/views.py:502-505`).
- **공지사항·알림·태스크 상세·시스템 관리·설정 프로필**: 운영 화면 구성에 맞게 문구 보강/수정(전체 읽음, 수신 채널·수신 프로젝트, GitHub 이슈·PR 연결, 삭제 대상 파일·백업 히스토리, 프로필에서 소속 그룹 제거).

### 캡처
- 운영 데이터(실제 고객사·태스크 제목)는 그대로 노출되며, 사람 이름·이메일·연락처·웹훅 이름/URL·S3 설정값만 흐림 처리했다. 매뉴얼은 공개 GitHub Pages라 게시 전 한 번 더 확인이 필요하다.
- 태스크 생성 및 연결 창은 열어서 촬영만 하고 **취소**했다(데이터 생성 없음).
- `manual.html` 크기: 1.51MB → 약 1.77MB.
