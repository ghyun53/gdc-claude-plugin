## 요청 내용

GDC 사용 매뉴얼(`site/manual.html`)에서 같은 사이트의 다른 안내서 두 개로 넘어갈 수 있게 '더 알아보기' 형태로 연결한다. 위치는 **매뉴얼 맨 끝**.

- GDC MCP 플러그인 사용 안내서 — https://seonmikii.github.io/gdc-claude-plugin/
- GDC 웹훅 연동 안내서 — https://seonmikii.github.io/gdc-claude-plugin/webhook.html

진행 중 추가 지시:
- MCP 안내서·웹훅 안내서에서도 매뉴얼로 돌아올 수 있게 하고, MCP ↔ 웹훅도 서로 오갈 수 있게 한다.

## 수행 계획

1. 본문 맨 끝(03장 뒤, footer 위)에 `04 더 알아보기` 장을 추가하고 안내서 두 개를 카드 링크로 넣는다.
2. 왼쪽 목차에 `04 더 알아보기` 항목을 추가한다.
3. 카드용 스타일을 기존 색·테두리 토큰으로 추가한다(좁은 화면에서는 1열).
4. (추가 지시) `site/index.html`에 `06 더 알아보기`(매뉴얼·웹훅), `site/webhook.html`에 `04 더 알아보기`(매뉴얼·MCP)를 같은 형태로 추가하고 각 목차에도 넣는다. 두 페이지는 한/영 전환을 지원하므로 문구마다 `data-en` 영문을 함께 넣는다.

```
목차                     본문 (매뉴얼 맨 끝, footer 위)
 01 GDC의 체계           ┌──────────────────────────────────────────────┐
 02 탭 한눈에 보기        │ 04                                           │
 03 탭별 안내            │ 더 알아보기                                   │
 04 더 알아보기  (+)      │ ┌────────────────────┐ ┌───────────────────┐ │
                         │ │ MCP 플러그인        │ │ 웹훅 연동          │ │
                         │ │ 사용 안내서      →  │ │ 안내서          →  │ │
                         │ └────────────────────┘ └───────────────────┘ │
                         └──────────────────────────────────────────────┘
```

| 페이지 | 추가한 장 | 연결 대상 |
|---|---|---|
| manual.html | 04 더 알아보기 | MCP 안내서 · 웹훅 안내서 |
| index.html (MCP) | 06 더 알아보기 | 매뉴얼 · 웹훅 안내서 |
| webhook.html | 04 더 알아보기 | 매뉴얼 · MCP 안내서 |

범위 밖: '알림' 탭 설명의 기존 웹훅 문장 링크와 웹훅 안내서 바닥글의 기존 MCP 안내서 링크(그대로 둠), 버전 표기.

## 참고 사항

- 변경 파일: `site/manual.html`, `site/index.html`, `site/webhook.html`
- `site/artifact.html`은 `index.html`에서 파생되는 미커밋 파일이라 손대지 않았다. 아티팩트로 다시 게시할 때는 `uv run python site/build-artifact.py`로 재생성한다.
- 링크는 '알림' 탭의 기존 웹훅 링크와 같은 절대 주소 방식을 따른다.
- MCP 도구/서버 동작과 무관한 문서 변경이라 로컬 사전 검증은 생략한다.
